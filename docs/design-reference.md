## 1. What this product is

**R²P ServiceManager** is the operational surface of **R²P (RU·RU·Partner) — Digital Railway
Communication**: a neutral platform for structured communication between railway undertakings
(EVU). It is a **desktop browser** app built on **Angular 22 + Angular Material 22 (M3, light
theme)**, Roboto, signals-first standalone components.

**The defining constraint — vendor neutrality.** The app serves *all* EVU equally and must
**never look like any single operator's product** (notably not SBB). Per-operator brand colours
are confined to small partner badges; they never touch the app chrome. A second job: in demos it
must read as a **finished product** at first glance — modern, fresh, clean, confident.

**Naming.** Always write the brand mark with the superscript ² — **"R²P"**, never `R2P` or `R^2P`.
The product name is **"R²P ServiceManager"** (browser title). In the top bar the navy logo tile
carries the "R²P" mark and the wordmark beside it reads "ServiceManager".

## 2. Brand palette (the rules that matter most)

Navy + a single vibrant orange + white, on airy light-grey surfaces. Use the **CSS variables**,
never hard-coded hex. Semantic aliases are defined in `src/styles.scss`.

| Token (CSS var) | Hex | Role |
|---|---|---|
| `--navy` | `#0D1B2A` | Structural voice: chrome accents, headings, body text on light, table headers, logo field |
| `--orange` | `#F47B20` | **Signal colour only** — CTA fills, top-bar hairline, active/selected states, filter count badge, logo `²` |
| `--orange-hover` | `#E06D14` | CTA hover/active |
| `--teal` | `#3D6880` | Secondary/tertiary text, captions, micro-labels, **links on light surfaces**, accent left-borders |
| `--steel` | `#8AAFC8` | Secondary text on dark, dividers, decorative lines, tints (below AA for small text on white) |
| `--light-grey` | `#F4F6F8` | Page/section background, alternating table rows |
| `--card-background` | `#ffffff` | Cards, top bar, text on dark |
| `--border-color` | `#CCCCCC` | Table/row borders |
| `--border-subtle` | `#E2E8F0` | Card/input/hairline borders |

### Hard colour rules (non-negotiable)

1. **Orange is a signal colour, never decoration.** It appears *only* as: CTA button **fills**
   (white text on orange), the **2px top-bar hairline**, **active/selected** states (e.g. active
   language tab underline, row hover chevron), the **filter-active count badge**, and the logo `²`.
2. **Orange text only on navy.** Never orange text on white or light grey. Interactive
   text/links on light surfaces use **navy or teal** (underline on hover). Never use orange as a
   table row/cell background.
3. **No gradients, drop shadows, or glow.** The app is **flat**. Build hierarchy with the
   navy/light-grey/white value structure and **1px borders** (`--border-color` for tables,
   `--border-subtle` for cards/inputs), never elevation. Modals sit over a flat dim scrim but are
   themselves flat with a 1px border.
4. **Operator colours stay in partner badges.** Never put a partner colour (`--partner-*`) in
   the app chrome.
5. The logo sits only on navy or white — never on orange, steel, or mid-tones.

### Functional (non-brand) palettes — keep as-is, they encode meaning

- **Overall-status shapes** (shape *and* colour, never colour-only): confirmed = green **circle**,
  proposed/requested = amber **square**, refused/dropped = red **triangle**. Never flatten these
  into one shape.
- **Branch/plan-status badges**: accessible tinted pills (`--status-*` families: open/blue,
  merged/green, deleted/red, merge-requested/amber).
- **Partner colours** (`--partner-sbb`, `--partner-bls`, …): partner badges only.

## 3. Typography

- **Family:** `Roboto, 'Segoe UI', sans-serif`, body 14px / line-height 1.5. Headings 700,
  body 400. **Sentence case** for headings ("Create new train", not "Create New Train").
- **Approved deviation:** the Brand Guidelines mandate Arial; the app deliberately **keeps Roboto**
  (Material default, already loaded). This is a recorded, approved exception — do not reintroduce
  Arial as a web font, and do not add other web fonts.
- **Micro-labels** (field/section labels, `.eyebrow`, `.info-label`): teal, ~11px, uppercase,
  letter-spaced, weight 700.
- **Code/JSON/identifiers:** Courier New monospace.

## 4. Layout, spacing, shape

- **Spacing scale** (rem, 4-based): `--spacing-xs` 0.25 · `sm` 0.5 · `md` 1 · `lg` 1.5 · `xl` 2 · `2xl` 3 rem.
- **Content** max-width **1400px**, centred (`.container`), on a light-grey page; page padding `--spacing-xl`.
- **Desktop browser only.** No mobile/tablet target. Wide tables scroll inside their own
  `overflow-x:auto` container — **the page body never scrolls horizontally.**
- **Top bar** is sticky, 64px, white, 1px bottom border + 2px orange hairline beneath. Edit
  screens add a sticky action bar below it.
- **Rounded scale:** status pills 4px · inputs/activity cards 6px · buttons/cards 8px · modals/top-level cards 10px · badges & language toggle pill (999px).

## 5. Component patterns (visual + behaviour)

| Component | Rules |
|---|---|
| **Top bar** | White, 64px, 1px border + 2px orange hairline. Left: navy logo tile (white R/P, orange ²) + "ServiceManager" wordmark + light-grey version pill. Right: "Organization:" + partner badge, EN \| DE toggle (active = navy text + orange underline), settings icon button. |
| **Buttons** | Primary = orange fill + white text (the *only* orange fills), hover `--orange-hover`. Secondary = white + navy text + 1px navy border. Ghost = teal text + 1px subtle border. Danger = red. |
| **Card** | White, 1px `--border-subtle`/`--border-color`, rounded, **no shadow**. |
| **Data table** | Navy header (white, uppercase, letter-spaced); body rows alternate white / light-grey; 1px borders; row hover = light-grey; clickable rows show a chevron that shifts + turns orange on hover. Never orange as a row/cell background. |
| **Status pill / badge** | Leading dot + functional tint family + a text label (never colour-only). |
| **Partner badge** | Small solid partner-coloured pill, white text — the only place operator colour is allowed. |
| **Overall-status shape** | circle/square/triangle + a "?" tooltip anchor explaining the legend. |
| **Filter bar** | Collapsed by default; "Filters" toggle (funnel + chevron). Active filters → orange count badge so collapsed state still signals filtering. |
| **Sticky edit bar** | White, 1px bottom border. Dirty state = amber dot + "Unsaved changes" (not a glow). Save disabled while invalid/saving/journey empty. |
| **Breadcrumb** | "Traffic overview › … › current"; earlier crumbs are teal links (underline on hover), current crumb muted. |
| **Modal** | White card, 1px border, rounded, flat, over a dim scrim. Settings modal is forced open (with a banner) when config is missing or auth fails. |

## 6. Interaction & content principles

- **Click-to-navigate:** train/variant rows are fully clickable with an explicit chevron;
  row-internal action buttons `stopPropagation`.
- **Disclosure:** filter bar and variant archive are collapsed by default; the collapsed state
  still communicates content (count badge / "Archive (N)").
- **Locale toggle:** EN \| DE switches locale live; active locale marked with an orange underline.
- **Microcopy:** sentence case; helpful empty states ("No trains found" + a next step), not
  "0 results"; plain action labels ("Save train"), never decorative-emoji labels.
- **Icons:** sparing and functional. A plain "+" covers add-actions. **No decorative emojis**
  (🚂 💾 📋 👁️ ⎇ 🔗 🗑).

## 7. Accessibility floor

- **WCAG 2.2 AA** across the desktop surface. Steel is for large/decorative use only; small
  secondary text uses teal to hold contrast.
- **Status is never colour-only** — pair with a shape and/or a text label.
- All interactive controls keyboard-reachable with a visible focus state; icon-only buttons have
  `aria-label`/`matTooltip`; the "?" anchor is focusable.
- **Both locales (EN + de-CH) are always in sync** — never ship an English-only user-facing
  string. (See AGENTS.md → i18n for the extract/sync workflow.)

## 8. Quick checklist before you commit UI work

- [ ] Used CSS variables (`--navy`, `--orange`, …), no new hard-coded hex.
- [ ] Orange used only as fill/hairline/active/badge/`²` — never as text on light, never a table background.
- [ ] Flat: no gradient, shadow, or glow; separation via 1px borders + value.
- [ ] Operator colour stayed inside partner badges.
- [ ] Status conveyed by shape and/or label, not colour alone.
- [ ] Sentence-case headings; no decorative emoji; plain "+" for add.
- [ ] New strings added to both EN source and `de-CH` (no English-only).
- [ ] No horizontal page scroll; wide tables scroll in their own container.
- [ ] Brand mark and product name written with the superscript: "R²P" / "R²P ServiceManager".
