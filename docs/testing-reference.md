> _This document was generated by an LLM (and is intended to be maintained with LLM

> **LLM Reference** – Primary focus: **Vitest** (default for Angular 21). Karma/Jasmine included for migration context.

## Setup & Configuration

```bash
ng test                          # Watch mode
ng test --no-watch --no-progress # CI / single run
ng test --coverage               # With coverage report
ng test --debug                  # Debug mode (attach Node.js debugger)
ng test --browsers=chromium      # Real browser (requires @vitest/browser-playwright)
```

### `angular.json` Test Options

```json
{
  "test": {
    "builder": "@angular/build:unit-test",
    "options": {
      "include": ["**/*.spec.ts"],        // default
      "setupFiles": ["src/setup.ts"],     // global setup / polyfills
      "providersFile": "src/test-providers.ts", // global Angular providers
      "coverage": false,
      "browsers": [],                     // e.g. ["chromium"] for browser mode
      "runnerConfig": "vitest-base.config.ts"   // custom Vitest config
    }
  }
}
```

**Global providers file** (`providersFile`):
```typescript
// src/test-providers.ts
import { provideHttpClientTesting } from '@angular/common/http/testing';
export default [provideHttpClientTesting()];
```
> Add setup/provider files to `tsconfig.spec.json` so TypeScript processes them.

**DOM emulation:** jsdom (default) or happy-dom. Install happy-dom to auto-switch.

**Coverage prerequisites:** `npm install --save-dev @vitest/coverage-v8`

## Vitest vs. Karma/Jasmine – Quick Reference

| Concern | Jasmine/Karma | Vitest |
|---|---|---|
| Imports | Globals (none needed) | `import { vi, describe, it, expect, beforeEach } from 'vitest'` |
| Mock function | `jasmine.createSpy()` | `vi.fn()` |
| Spy on method | `spyOn(obj, 'method')` | `vi.spyOn(obj, 'method')` |
| Fake timers | `jasmine.clock().install()` | `vi.useFakeTimers()` / `vi.useRealTimers()` |
| Partial match | `jasmine.objectContaining({})` | `expect.objectContaining({})` |
| Any instance | `jasmine.any(Class)` | `expect.any(Class)` |
| Focused test/suite | `fit` / `fdescribe` | `it.only` / `describe.only` |
| Skip test/suite | `xit` / `xdescribe` | `it.skip` / `describe.skip` |
| Boolean matchers | `toBeTrue()` / `toBeFalse()` | `toBe(true)` / `toBe(false)` |
| `fakeAsync` / `tick` | ✅ | ❌ **NOT supported** in Vitest |
| `waitForAsync` | ✅ | ❌ **NOT supported** in Vitest |
| Async strategy | `fakeAsync` + `tick` | native `async/await` + `vi.useFakeTimers()` |

## Test File Structure

```typescript
import { vi, describe, it, expect, beforeEach } from 'vitest';
import { TestBed, ComponentFixture } from '@angular/core/testing';
import { MyComponent } from './my-component';

describe('MyComponent', () => {
  let component: MyComponent;
  let fixture: ComponentFixture<MyComponent>;

  beforeEach(async () => {
    await TestBed.configureTestingModule({
      imports: [MyComponent],
      providers: [{ provide: MyService, useValue: mockService }],
    }).compileComponents(); // Only needed when @defer blocks are used

    fixture = TestBed.createComponent(MyComponent);
    component = fixture.componentInstance;
    await fixture.whenStable(); // Wait for initial render
  });

  it('should create', () => {
    expect(component).toBeDefined();
  });
});
```

> ⚠️ Do NOT re-configure `TestBed` after `createComponent()` – the config is frozen.

## TestBed API

```typescript
// Configure module (call before createComponent)
TestBed.configureTestingModule({
  imports: [StandaloneComponent, SomeModule],
  providers: [{ provide: MyService, useValue: stub }],
  schemas: [NO_ERRORS_SCHEMA], // Suppress unknown element errors
});

// Create component
const fixture = TestBed.createComponent(MyComponent);

// Inject service from root injector
const svc = TestBed.inject(MyService);
const opt = TestBed.inject(OptionalService, null); // null fallback

// Override component/directive/pipe metadata
TestBed.overrideComponent(MyComponent, {
  set: { providers: [{ provide: MyService, useClass: MySpy }] },
  // add?: / remove?: for partial changes
});
```

**`MetadataOverride<T>`:** `{ add?, remove?, set? }` — `set` replaces entirely, `add`/`remove` are selective.

## ComponentFixture & DebugElement

### Key Members

| API | Description |
|---|---|
| `fixture.componentInstance` | The component instance |
| `fixture.nativeElement` | Root DOM element (`HTMLElement`) |
| `fixture.debugElement` | Root `DebugElement` |
| `fixture.whenStable()` | `Promise` resolving when all async tasks finish |
| `fixture.detectChanges()` | Trigger change detection manually |
| `fixture.componentRef.setInput('name', val)` | Set signal inputs |

### DebugElement

```typescript
import { DebugElement } from '@angular/core';
import { By } from '@angular/platform-browser';

const de = fixture.debugElement;

// Query elements
de.query(By.css('h1'))                    // First match
de.queryAll(By.css('li'))                 // All matches
de.queryAll(By.directive(MyDirective))    // By directive
de.query(By.css('h2:not([highlight])'))   // Negation

// Access
de.nativeElement                          // Underlying HTMLElement
de.injector.get(MyService)                // Element-scoped service
de.triggerEventHandler('click', { button: 0 }) // Fire event
de.styles                                 // Style map
de.properties                             // Property map
```

> Prefer `fixture.nativeElement.querySelector()` for simple cases; use `DebugElement` for cross-platform or directive-based queries.

## Testing Components

### Basic Pattern

```typescript
beforeEach(async () => {
  fixture = TestBed.createComponent(MyComponent);
  component = fixture.componentInstance;
  await fixture.whenStable();
});

it('displays title', () => {
  expect(fixture.nativeElement.querySelector('h1').textContent).toContain('Title');
});

it('updates on signal change', async () => {
  component.title.set('New');
  await fixture.whenStable();
  expect(fixture.nativeElement.querySelector('h1').textContent).toContain('New');
});
```

### Simulating User Input

```typescript
const input: HTMLInputElement = fixture.nativeElement.querySelector('input')!;
input.value = 'new value';
input.dispatchEvent(new Event('input')); // Notify Angular
await fixture.whenStable();
```

### Setting Signal Inputs

```typescript
fixture.componentRef.setInput('hero', { id: 1, name: 'Test' });
await fixture.whenStable();
```

### Dynamic Input/Output Bindings

```typescript
import { inputBinding, outputBinding } from '@angular/core';
const valueSignal = signal('hello');
TestBed.createComponent(MyComponent, {
  bindings: [
    inputBinding('value', valueSignal),
    outputBinding('valueChange', (v) => { /* handle */ }),
  ],
});
```

### Stubbing Child Components / Shallow Testing

```typescript
// Option 1: Stub components
@Component({ selector: 'app-header', template: '' }) class HeaderStub {}
TestBed.configureTestingModule({...}).overrideComponent(AppComponent, {
  set: { imports: [RouterLink, HeaderStub] }, // replaces ALL imports
});

// Option 2: NO_ERRORS_SCHEMA
.overrideComponent(AppComponent, {
  set: { imports: [], schemas: [NO_ERRORS_SCHEMA] },
});

// Option 3: Combination (recommended)
.overrideComponent(AppComponent, {
  remove: { imports: [RouterOutlet, WelcomeComponent] },
  set: { schemas: [NO_ERRORS_SCHEMA] },
});
```

### Overriding Component-Level Providers

When a component declares its own `providers: [...]` in `@Component`:
```typescript
TestBed.overrideComponent(HeroDetail, {
  set: { providers: [{ provide: HeroDetailService, useClass: HeroDetailServiceSpy }] },
});
// Must retrieve from component's own injector:
const spy = harness.routeDebugElement!.injector.get(HeroDetailService) as HeroDetailServiceSpy;
```

### Click Events

```typescript
heroEl.click();                                         // Native element
heroDe.triggerEventHandler('click', { button: 0 });     // DebugElement (needed for RouterLink)
```

### Test Host Pattern

```typescript
@Component({
  imports: [DashboardHeroComponent],
  template: `<dashboard-hero [hero]="hero" (selected)="onSelected($event)" />`,
})
class TestHost {
  hero: Hero = { id: 42, name: 'Test' };
  selectedHero?: Hero;
  onSelected(h: Hero) { this.selectedHero = h; }
}
fixture = TestBed.createComponent(TestHost);
```

## Testing Routing & Navigation

### Setup

```typescript
import { RouterTestingHarness } from '@angular/router/testing';
import { provideRouter, Router } from '@angular/router';
```

### Route Parameters

```typescript
TestBed.configureTestingModule({
  providers: [provideRouter([{ path: 'user/:id', component: UserProfile }])],
});
const harness = await RouterTestingHarness.create();
await harness.navigateByUrl('/user/123', UserProfile);
expect(harness.routeNativeElement?.textContent).toContain('123');
```

### Route Guards

```typescript
const authStore = { isAuthenticated: vi.fn().mockReturnValue(true) };
TestBed.configureTestingModule({
  providers: [
    { provide: AuthStore, useValue: authStore },
    provideRouter([
      { path: 'protected', component: Protected, canActivate: [authGuard] },
      { path: 'login', component: Login },
    ]),
  ],
});
const harness = await RouterTestingHarness.create();
await harness.navigateByUrl('/protected', Protected); // → renders Protected
// or with isAuthenticated returning false → renders Login
```

### Query Parameters

```typescript
const component = await harness.navigateByUrl('/search?q=angular', SearchComponent);
expect(component.searchTerm()).toBe('angular');
```

### Best Practices

- Use `RouterTestingHarness` for routed components
- **Never mock `Router`** – use real `provideRouter([...])`
- Navigation is async – always `async/await`
- Test guard rejections and invalid routes

## Async Testing with Vitest

### Native async/await (default)

```typescript
it('loads data', async () => {
  await fixture.whenStable();
  expect(fixture.nativeElement.querySelector('.data').textContent).toBe('loaded');
});
```

### Fake Timers

Use for `setTimeout`, `setInterval`, Promise-based delays:

```typescript
it('handles delayed response', async () => {
  vi.useFakeTimers();
  const fixture = TestBed.createComponent(MyComponent);

  await vi.runAllTimersAsync();   // Flush all timers and pending promises

  expect(fixture.nativeElement.querySelector('.result').textContent).toBe('done');
  vi.useRealTimers();             // Always reset
});
```

> ⚠️ `fakeAsync`, `tick`, `flush`, `waitForAsync` do **not** work in Vitest.

## Mocking & Spying

```typescript
import { vi, type Mocked } from 'vitest';

// Mock function
const fn = vi.fn();
fn.mockReturnValue(42);
fn.mockResolvedValue('async');
fn.mockReturnValueOnce(1);

// Assertions
expect(fn).toHaveBeenCalledTimes(1);
expect(fn).toHaveBeenCalledWith('arg');
expect(fn).toHaveBeenCalledExactlyOnce();

// Spy on method
const spy = vi.spyOn(service, 'getData').mockReturnValue(of([]));
spy.mockRestore(); // after test

// Type-safe stub
const stub: Mocked<MyService> = { getData: vi.fn(), save: vi.fn() };
stub.getData.mockReturnValue(of(testData));
TestBed.configureTestingModule({
  providers: [{ provide: MyService, useValue: stub }],
});
```

## HTTP Testing

```typescript
import { provideHttpClient } from '@angular/common/http';
import { provideHttpClientTesting, HttpTestingController } from '@angular/common/http/testing';

beforeEach(() => {
  TestBed.configureTestingModule({
    providers: [provideHttpClient(), provideHttpClientTesting(), MyService],
  });
});

it('fetches heroes', () => {
  const service = TestBed.inject(MyService);
  const httpMock = TestBed.inject(HttpTestingController);

  service.getHeroes().subscribe(heroes => expect(heroes.length).toBe(2));

  const req = httpMock.expectOne('api/heroes');
  expect(req.request.method).toBe('GET');
  req.flush([{ id: 1, name: 'A' }, { id: 2, name: 'B' }]);
  httpMock.verify();
});
```

## Component Harnesses

```typescript
import { TestbedHarnessEnvironment } from '@angular/cdk/testing/testbed';

const fixture = TestBed.createComponent(MyComponent);
const loader = TestbedHarnessEnvironment.loader(fixture);
const rootLoader = TestbedHarnessEnvironment.documentRootLoader(fixture); // for overlays/dialogs

const button = await loader.getHarness(MatButtonHarness);
const buttons = await loader.getAllHarnesses(MatButtonHarness);
const disabled = await loader.getHarness(MatButtonHarness.with({ selector: '[disabled]' }));

expect(await button.getText()).toBe('Submit');
```

### Creating a Harness

```typescript
import { ComponentHarness, HarnessPredicate } from '@angular/cdk/testing';

class MyButtonHarness extends ComponentHarness {
  static hostSelector = 'my-button';

  static with(options: { text?: string } = {}) {
    return new HarnessPredicate(MyButtonHarness, options).addOption(
      'text', options.text,
      (h, text) => HarnessPredicate.stringMatches(h.getText(), text),
    );
  }

  private getButton = this.locatorFor('button');
  async click() { (await this.getButton()).click(); }
  async getText() { return (await this.host()).text(); }
}
```

## Migrating Karma → Vitest

### Manual Steps

```bash
# 1. Install
npm install --save-dev vitest jsdom

# 2. Update angular.json builder to @angular/build:unit-test (remove karma options)

# 3. Remove Karma
npm uninstall karma karma-chrome-launcher karma-coverage karma-jasmine karma-jasmine-html-reporter jasmine-core
# Delete: karma.conf.js, src/test.ts
```

### Automated Schematic (Experimental)

```bash
ng g @schematics/angular:refactor-jasmine-vitest
# Options: --project, --include, --add-imports, --verbose, --browser-mode
```

**Auto-converted:**
- `fit`/`fdescribe` → `it.only`/`describe.only`
- `xit`/`xdescribe` → `it.skip`/`describe.skip`
- `spyOn` → `vi.spyOn`, `jasmine.createSpy` → `vi.fn()`
- `jasmine.objectContaining` → `expect.objectContaining`
- `jasmine.any` → `expect.any`

**Requires manual migration:**
- `fakeAsync`/`tick`/`flush` → native `async/await` + `vi.useFakeTimers()`
- `toBeTrue()`/`toBeFalse()` → `toBe(true)`/`toBe(false)`
- Complex spy/mock scenarios

### Keep Karma (if needed)

```json
// angular.json
{ "test": { "builder": "@angular/build:unit-test", "options": { "runner": "karma" } } }
```

Add `"types": ["jasmine"]` to `tsconfig.spec.json`.

## Zone.js Utilities (Karma Only – Not for Vitest)

| Function | Description |
|---|---|
| `fakeAsync(fn)` | Runs test in fake async zone |
| `tick(ms?)` | Flushes timers + micro-task queues |
| `discardPeriodicTasks()` | Discards pending `setInterval` tasks |
| `flushMicrotasks()` | Flushes micro-task queue |
| `waitForAsync(fn)` | Completes when zone is stable |

> These functions are **only available with Karma**. Not applicable in Vitest projects.
